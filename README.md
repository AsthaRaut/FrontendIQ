# FrontendIQ

An interactive, web-based assessment application designed to evaluate technical proficiency in **JavaScript and CSS** through timed, multi-level multiple-choice evaluations.

[![Live Demo](https://img.shields.io/badge/Demo-Live%20Application-brightgreen?style=for-the-badge)](https://frontendiq.netlify.app/)

## 📋 Overview

**FrontendIQ** provides a structured platform for developers to evaluate and reinforce their frontend development knowledge. Featuring adaptive difficulty tiers, strict time constraints, dynamic feedback, and automated performance accreditation, the application delivers a polished, responsive testing environment.

## 🔑 Key Features

- **Multi-Track Assessment Tiers:** Select specialized evaluations across JavaScript, CSS, or a comprehensive Hybrid track.
- **Graded Difficulty Levels:** Tailored question sets spanning Beginner, Intermediate, and Advanced tiers.
- **Time-Constrained Evaluations:** Integrated 15-second countdown timer per question to simulate high-pressure problem-solving.
- **Real-Time Feedback & Analytics:** Instant response validation with final score generation calculated as a percentage.
- **Performance Ranking & Certification:** Dynamic score-based ranking system paired with a customized completion certificate displaying candidate details, track parameters, and assessment metrics.
- **Auditory & Visual Indicators:** Audio-cued countdown notifications for improved user engagement during critical time intervals.
- **Session Management:** Seamless evaluation resets for iterative testing and skill improvement.

## 🛠️ Technology Stack

| Layer | Technologies |
|---|---|
| **Frontend Core** | HTML5, CSS3 |
| **Logic & State Management** | JavaScript (ES6+) |
| **Deployment Platform** | Netlify |

## 📚 Assessment Topics

| Track | Covered Domains |
|---|---|
| **JavaScript** | Data Types, Scope & Closures, DOM Manipulation, Asynchronous JS (Promises/Async-Await), Event Loop, and ES6+ Features |
| **CSS** | CSS Architecture, Specificity & Cascade, Box Model, Layout Systems (Flexbox & Grid), Transformations, and Animation Mechanics |
| **Hybrid** | Integrated assessment combining core JavaScript logic and advanced CSS concepts |
